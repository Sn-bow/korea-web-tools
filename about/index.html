도구 소개

한 틀 더는 작은
계량 준비 실험입니다.

그램 레시피를 붙여넣고 직접 확인한 뒤, 틀 면적에 맞게 재료를 환산하고 계량 체크리스트로 쓰는 한국어 도구입니다.

지금 제공하는 기능

  • 그램 재료의 보수적인 자동 해석과 사람이 확인하는 수정 단계
  • 원형·사각형 틀과 틀 개수의 면적 비율 계산
  • 계량 체크, 인쇄, 버튼을 눌렀을 때만 이루어지는 브라우저 저장

외부 라이브러리, 계정, 서버 계산, 광고, 분석 도구를 넣지 않았습니다. 재료 입력을 외부로 보내는 기능도 없습니다.

아직 말할 수 없는 것

계산과 상태 관리에 대한 자동 테스트는 베이킹 결과, 실제 사용성, 모든 브라우저 호환성을 입증하지 않습니다. 모든 실기기와 보조기술에서 검증한 상태도 아닙니다.

제과 전문가의 검토를 받았다는 주장이나 수익·검색 노출 보장은 하지 않습니다. 입력을 확인하고, 검증된 레시피와 틀 제조사의 주의사항을 함께 따르세요.

공개 피드백

기능 오류나 개선 제안은 공개 GitHub 이슈에 남길 수 있습니다. GitHub 계정이 필요하며 게시한 내용은 누구나 읽을 수 있습니다. 개인정보, 비밀번호, 비공개 레시피나 서버 로그를 올리지 마세요. 별도의 비공개 운영자 문의 주소는 현재 안내하지 않습니다.

이 도구를 쓰기 위해 개인정보를 입력하거나 보내야 하는 기능은 없습니다. 저장 방식과 서버 오류 기록은 개인정보 안내를 읽어 주세요.
